# Hospital Emergency Room Analytics Dashboard

## Overview
This project features an interactive Hospital Dashboard built entirely in Microsoft Excel. It analyzes emergency room operational data to uncover insights into patient admission patterns, department referrals, demographic distributions, and overall healthcare service performance. 

The dashboard provides a high-level view of critical hospital metrics to help stakeholders understand patient flow, optimize resource utilization, and improve the patient experience.

## Dataset Details
The analysis is built on a comprehensive dataset containing emergency room records, including:
* **Patient Demographics:** Age, Gender, and Race distributions.
* **Operational Metrics:** Admission Dates/Times, Department Referrals, and Admission Flags.
* **Quality of Care Indicators:** Patient Wait Times (minutes) and Patient Satisfaction Scores.

## Key Features & Insights
* **Patient Flow Analysis:** Tracks admissions across different years, months, and hours of the day to identify peak operational times.
* **Wait Time Tracking:** Averages and trends for patient wait times before receiving care.
* **Patient Satisfaction:** Aggregated satisfaction scores correlated with different demographics and departments.
* **Interactive Dashboard:** Utilizes Excel Pivot Tables and connected slicers to allow dynamic filtering of the data.

## Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, transformation, and visualization.
* **Pivot Tables & Charts:** For dynamic data aggregation and dashboard construction.
* **Data Modeling:** Connected datasets spanning raw operational data to final dashboard views.

## How to Use This Project
1. Clone the repository or download the `Hospital Dashboard.xlsx` file directly.
2. Open the file in **Microsoft Excel** (Version 2016 or newer recommended for full interactive feature support).
3. Navigate to the **"Dashboard"** sheet to interact with the visual interface.
4. Use the slicers and filters to drill down into specific months, departments, or patient demographics.
5. The raw data and aggregation logic can be viewed in the **"Hospital Emergency Room Data"** and **"Pivot"** sheets.
